Puntos de decisión

Decisiones
D1¿Existe RCP vigente para la categoría?
Sí → modelado · No → PT-02
D2¿La DAP agrupa varios productos?
Sí → declarar método de agregación · No → producto único
D3¿Hay datos primarios disponibles para el proceso?
Sí → usarlos · No → secundarios representativos · Si tampoco → proxy bajo el límite del 10%
D4¿La RCP permite el módulo D?
Sí → declarar por separado · No → excluirlo
D5¿La DAP incluye afirmaciones comparativas?
Sí → cumplir las cinco condiciones del 9 · No → sin declaración comparativa
